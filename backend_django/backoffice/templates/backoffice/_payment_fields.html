{% comment %} Payment credentials block, shared by the branch form and the shop settings page. Rendered with the context from ``views._payment_context`` plus a ``payment_scope`` of "branch" or "template", which only changes the wording — the fields, the names and the write-only handling are identical, and ``views._apply_payment_form`` reads them the same way for both. Secrets are never emitted into the HTML: the key inputs start empty and show ••••1234 as placeholder text, so a saved key can be replaced but not read back off the page (or out of a browser's saved-form cache, or a screenshot). The Live/Test lane is the loudest thing in the panel because it is the one setting here whose consequence is real money. {% endcomment %}
