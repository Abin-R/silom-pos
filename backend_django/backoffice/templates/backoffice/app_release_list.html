How this works
Staff install from {{ install_url }} — a public page with a download button and a QR code, so a tablet with no login can reach it.
The APK stays in Google Drive; that page redirects to it, and the file never passes through this server. Each build must be shared anyone with the link, or a new tablet can’t fetch it.
The newest Listed build is the one offered by default. To withdraw one, un-tick Listed — the build below it becomes current again.
Only native changes need a new APK: JS-only changes already reach the tills over eas update on the preview channel.
